# MNEME Notes

The note-taking app behind MNEME. A note can be sent to an analyze route and a categorize route. The Hugging Face inference client is the model connection.

**Live app:** [note-application-kappa.vercel.app](https://note-application-kappa.vercel.app)

The public landing page is [website-mneme](https://github.com/busenur-durak/website-mneme).

## Stack

Next.js, React, TypeScript, Tailwind CSS, Hugging Face Inference

## Run

```bash
npm install
npm run dev
```
